
# My Python Toolkit

## Project Description

My Python Toolkit is a simple command-line application developed using Python. It contains three useful tools that demonstrate basic Python programming concepts such as functions, loops, lists, conditionals, exception handling and f-strings.

### Tools Included

1. **Countdown Timer:** Allows the user to enter a number of seconds and counts down to zero.
2. **Shopping List Manager:** Allows the user to add, remove and view items in a shopping list.
3. **Simple Calculator:** Performs addition, subtraction, multiplication and division.

## How to Run the Program

Follow these steps to run the toolkit:

1. Install Python on your computer.
2. Download or clone this project from GitHub.
3. Open the project folder in your terminal or command prompt.
4. Run the following command:

```bash
python toolkit.py
```

5. The main menu will appear. Select a tool by entering the corresponding number.
6. Follow the instructions displayed on the screen.

## Reflection

The hardest part of this project was combining the three tools into one program using functions and a main menu. The part that took the longest to fix was handling invalid user inputs, especially when the user entered text instead of numbers. I learned how to use try and except to prevent the program from crashing when invalid input is entered. I also improved my understanding of loops, lists, conditionals and functions. If I had one more week, I would add more tools such as a password generator and a unit converter. I would also improve the user interface to make the toolkit more interactive and user-friendly.
